# System Reference Document 5.2, as text

Reference text for agents and reviewers checking rules content. It is not
loaded by the game and is not copied into `dist/`.

- `srd52-flow.txt`: reading order, one column at a time (`pdftotext`). Use
  this one to read rules and stat blocks.
- `srd52.txt`: page layout kept, two columns side by side (`pdftotext -layout`).
  Use it only to untangle a table.

Both are unedited extractions of the official SRD 5.2 PDF, which is beside them as
`SRD_CC_v5.2.pdf` and is published at
https://www.dndbeyond.com/srd.
