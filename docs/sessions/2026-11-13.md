## What went wrong, and what was learned

- **Three workspace restarts.** The workspace has two CPU cores; up to six agents were each
  running headless browsers. Agents were stopped mid-run and resumed; nothing was lost, but
  hours were. Rule since: two browser-checking agents at most, named smoke passes only.
- **The lead committed conflict markers** into `docs/DEBT.md` (#157), fixed in #158. Rule since:
  grep for markers after every merge of main.
- **`SMOKE_ONLY=solo` runs nothing and reports success.** The lead used it as a check several
  times before noticing. `SMOKE_ONLY=base` now exists.
- **Smoke steps that looked like game bugs were test bugs**: a rate-limit step that depended on
  machine speed, and a move step that tapped an ally once the party stood side by side.
- **A change broke an import silently**: class features made duplicate Metamagic picks an error,
  so one character file stopped loading until #186. An importer must never produce a sheet the
  engine refuses; it now has a test for that.
- **The spell re-tier job could raise only one spell**: the vocabulary was the limit, not the
  data. The useful output was the list of missing vocabulary, which became #174.
- **An independent reader finds what the builder's tests do not**: the review of #164 found
  Wild Shape wiping a druid's own resistances. Large engine changes get a second reader.
- **The long conversation became the main cost.** Each lead turn re-reads the whole of it.
- **Estimates in specs are not measurements**: the Three.js size was three times the draft's
  figure once measured.
