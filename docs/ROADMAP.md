# Roadmap

Each milestone ends with something playable.

## Done

- **Playable solo game.** Free roaming, hex-locked fights, enforced SRD 5.2
  combat, character sheets, DM tools, themes, monster AI. Runs on PC and phone.
- **Repo, tests and CI.** The prototype is in the repo with engine tests that
  run on every push.
- **Online (solo).** Every merge to `main` deploys to GitHub Pages.
- **Table server.** Host a table, join by code, DM approval, one character per
  player, saved between restarts, automatic rejoin.

## Next

| # | Milestone | Done when |
|---|---|---|
| 1 | Server hosting | The server runs on an always-on host with a disk, and a group can play from a link |
| 2 | Your campaign's characters | Character creation, or entering existing characters, at any level |
| 3 | More of the SRD | Spells, monsters and equipment in bulk as data, with concentration and the remaining conditions |
| 4 | Maps | A map editor or import, with terrain height |

## Later

- Visibility and fog of war, so players do not receive what their characters cannot see
- 3D character models, then animation
- Persistent world across sessions
- AI DM and AI characters reading the timeline
- Model import and full skins
